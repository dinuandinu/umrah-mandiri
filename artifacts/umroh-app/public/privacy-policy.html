Umroh Mandiri

📅 Terakhir diperbarui: 3 Juni 2026

📋 Tentang Aplikasi

Umroh Mandiri adalah aplikasi panduan digital independen yang dirancang untuk membantu jamaah merencanakan dan melaksanakan ibadah umroh secara mandiri. Kami berkomitmen untuk menjaga privasi dan keamanan data pengguna kami.

🔒 Pengumpulan Data

Aplikasi Umroh Mandiri tidak mengumpulkan, mengirim, atau membagikan data pribadi pengguna.

Kami tidak melakukan hal-hal berikut:

  • Tidak meminta identitas seperti Nama, Email, atau No. Telepon.
  • Tidak memerlukan pendaftaran akun atau integrasi media sosial.
  • Tidak mengakses Kamera, Mikrofon, Galeri, atau Lokasi perangkat Anda.
  • Tidak menggunakan layanan analitik pihak ketiga atau pelacak iklan.

💾 Penyimpanan Lokal (Local Storage)

Untuk memberikan fungsionalitas terbaik, aplikasi ini menyimpan data preferensi tertentu secara lokal di browser perangkat Anda menggunakan teknologi localStorage.

Data yang disimpan secara lokal meliputi:

  • Status checklist persiapan (item mana yang sudah Anda centang).
  • Pilihan tema tampilan (Terang/Gelap).
  • Pilihan ukuran teks (Normal/Besar).

Data ini tetap berada di perangkat Anda, tidak pernah dikirim ke server kami, dan dapat Anda hapus sepenuhnya kapan saja melalui menu "Reset Progress" di dalam aplikasi.

🌐 Penggunaan Offline

Aplikasi ini dirancang untuk bekerja sepenuhnya secara offline setelah pemuatan pertama. Kami tidak berkomunikasi dengan server pihak ketiga selama penggunaan rutin, guna memastikan privasi penuh dan penghematan paket data Anda saat berada di luar negeri.

🔄 Perubahan Kebijakan

Kami dapat memperbarui kebijakan privasi ini secara berkala seiring dengan penambahan fitur baru. Setiap perubahan akan diinformasikan dengan memperbarui tanggal "Terakhir diperbarui" di bagian atas halaman ini.
