# Panduan & Protokol Agent

> [!IMPORTANT]
> **PROTOKOL WAJIB**: Setiap Agent yang baru masuk atau memulai sesi di proyek ini **WAJIB** membaca file `README.md`, `TASKS.md`, dan `LOG.md` di direktori ini sebelum melakukan tindakan apa pun.

Direktori ini digunakan untuk koordinasi tugas dan pencatatan aktivitas Agent dalam proyek ini agar terjadi kesinambungan antar sesi Agent.

## File Utama

- **[TASKS.md](./TASKS.md)**: Daftar tugas yang perlu dilakukan, sedang dikerjakan, dan sudah selesai.
- **[LOG.md](./LOG.md)**: Catatan kronologis harian/sesi mengenai apa saja yang telah dikerjakan.

## Cara Menggunakan (Standard Operating Procedure)

1.  **Baca Konteks (WAJIB)**: Periksa `TASKS.md` untuk memahami prioritas saat ini dan `LOG.md` untuk memahami apa yang baru saja dilakukan oleh Agent sebelumnya.
2.  **Update Status**: Saat mulai mengerjakan sebuah tugas, pindahkan tugas tersebut ke bagian "In Progress" di `TASKS.md`.
3.  **Catat Aktivitas**: Tuliskan detail teknis, perubahan file, atau temuan penting secara real-time di `LOG.md`.
4.  **Finalisasi**: Setelah selesai, pindahkan tugas ke "Completed" di `TASKS.md` dan berikan ringkasan penutup sesi di `LOG.md`.
