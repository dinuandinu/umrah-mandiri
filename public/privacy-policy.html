Umroh Mandiri — Aplikasi Panduan Ibadah

📅 Terakhir diperbarui: 27 Mei 2026

📋 Tentang Aplikasi Ini

Umroh Mandiri adalah aplikasi panduan ibadah umroh untuk jamaah mandiri. Aplikasi ini dikembangkan secara pribadi dan tidak berafiliasi dengan pemerintah, biro perjalanan, atau lembaga keagamaan mana pun.

🔒 Data yang Kami Kumpulkan

Aplikasi Umroh Mandiri tidak mengumpulkan data pribadi pengguna.

Secara spesifik, aplikasi ini:

  • Tidak meminta nama, email, atau nomor telepon
  • Tidak memerlukan akun atau registrasi
  • Tidak mengakses kamera, mikrofon, atau galeri foto
  • Tidak mengakses lokasi perangkat
  • Tidak mengirimkan data apapun ke server eksternal
  • Tidak menggunakan layanan analitik atau pelacakan

💾 Penyimpanan Lokal

Satu-satunya data yang disimpan adalah progres checklist persiapan yang tersimpan secara lokal di perangkat Anda (menggunakan localStorage browser). Data ini:

  • Hanya tersimpan di perangkat Anda sendiri
  • Tidak pernah dikirim ke server manapun
  • Dapat dihapus kapan saja melalui pengaturan aplikasi

🌐 Koneksi Internet

Aplikasi ini dapat digunakan sepenuhnya secara offline. Koneksi internet hanya dibutuhkan saat pertama kali memuat aplikasi. Tidak ada komunikasi data ke server pihak ketiga.

👶 Privasi Anak-Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia 13 tahun dan tidak mengumpulkan informasi dari anak-anak.

🔄 Perubahan Kebijakan

Kebijakan privasi ini dapat diperbarui sewaktu-waktu. Perubahan akan ditandai dengan memperbarui tanggal "Terakhir diperbarui" di bagian atas halaman ini. Penggunaan berkelanjutan atas aplikasi berarti Anda menyetujui kebijakan yang berlaku.

⚖️ Hukum yang Berlaku

Kebijakan privasi ini tunduk pada hukum yang berlaku di Republik Indonesia.
